# Changelog

## 1.0.1

See the [short patch notes](docs/patch_notes_v1.0.1.md).

- Fixed archived-board validation and state carryover between loaded experiments.
- Improved responsiveness while discovering large raw-data collections and fixed rescanning.
- Simplified antenna assignment and made its dialog fit the visible controls.
- Added support for four live RFID DAQ boards, with one panel shown by default.
- Added TTL totals, muted unlisted tags and refined acquisition controls.
- Added per-mouse tag matching and column-aligned metadata sharing controls.
- Preserved canonical config, diagnostic and data formats and existing experiment file types.

## 1.0.0

- Windows RFID/TTL, camera and lighting acquisition with experiment metadata and layout editing.
- Raw-data preprocessing, interpolation, diagnostics and supported historical recording formats.
- uv installation, native Windows shortcuts, System check and update checks.
- Light, Dark and System appearance with bundled fonts and icons.
- Draft metadata saving, manually declared legacy clock offsets and protected wheel scrolling.
- Config v8, acquisition GUI state v1, diagnostics v12 and Parquet schema v5.
