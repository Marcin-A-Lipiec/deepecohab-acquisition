# DeepEcoHAB Acquisition v1.0.0

- Windows RFID/TTL, camera and lighting acquisition.
- Experiment metadata, EcoHAB layout editing and tag matching.
- Raw-data preprocessing, interpolation, diagnostic reports and historical formats.
- uv installation, native Windows shortcuts and System check.
- Light, Dark and System appearance with bundled fonts and icons.
- Draft metadata saving and explicit legacy PC-clock offset handling.
- User-requested release checks, documented updates and rollback.
- Config v8, acquisition GUI state v1, diagnostics v12 and Parquet schema v5.

See the [installation guide](INSTALLATION.md), [user guide](USER_GUIDE.md) and
[license](../LICENSE). Camera SDKs, matching vendor wheels and external video
tools are installed separately as described in the camera setup documentation.
